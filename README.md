# GYfiller (GBP Filler) · расширение Chrome

Панель для сети карточек Google Business Profile. Она читает карточки и список компаний из Google в локальную сеть, позволяет вести единый шаблон и прайс-лист и сверяет карточки перед записью.

**Текущая версия: 0.7.1a.** Это сборка **без записи в Google**: она только читает. Поэтому её можно спокойно пробовать на любом профиле.

## Установка

Ставится один раз, около 5 минут. Git не нужен.

1. Создайте папку **`C:\GYfiller`**. Это постоянное место расширения: потом её не переносите и не переименовывайте.
2. На этой странице нажмите зелёную кнопку **Code → Download ZIP**.
3. Распакуйте архив. Внутри будет папка `gyfiller-main`.
4. Скопируйте из неё папку **`extension`** в `C:\GYfiller`. Должно получиться `C:\GYfiller\extension`.
5. Откройте в Chrome `chrome://extensions` и включите **«Режим разработчика»** (переключатель справа вверху).
6. Нажмите **«Загрузить распакованное расширение»** и выберите папку **`C:\GYfiller\extension`**.
7. Закрепите значок GBP Filler на панели Chrome (значок пазла → булавка).

Архив и папку `gyfiller-main` после этого можно удалить.

> Если у вас уже стоит другая копия GBP Filler, сначала выключите её на `chrome://extensions`. Две копии одновременно будут мешать друг другу.

## Обновление

1. Скачайте архив заново: **Code → Download ZIP**, затем распакуйте.
2. Удалите старую папку `C:\GYfiller\extension`.
3. Скопируйте новую папку `extension` из архива **на то же место**, чтобы снова получилось `C:\GYfiller\extension`.
4. `chrome://extensions` → в карточке GBP Filler нажмите **«Обновить»** (круглая стрелка).
5. Обновите вкладки Google, с которыми работаете (F5).

**Главное правило:** путь всегда `C:\GYfiller\extension`. Ваши данные (сети, шаблоны, история) хранятся в браузере и привязаны к этому пути. Если загрузить расширение из другой папки, Chrome будет считать его новым расширением с пустыми данными. Старые данные никуда не денутся, но окажутся в старой копии.

Сам Chrome такое расширение не обновит, это происходит только через Chrome Web Store. Поэтому о новой версии вам сообщат, а обновить её нужно по шагам выше. Что изменилось в ней, смотрите в [CHANGELOG](CHANGELOG.md).

<details><summary>Если пользуетесь GitHub Desktop</summary>

Клонируйте репозиторий и загрузите в Chrome папку `gyfiller\extension` из клона. Обновление: **Fetch → Pull**, затем «Обновить» на `chrome://extensions`.
</details>

**Какая версия у меня стоит:** её показывает `chrome://extensions` → GBP Filler → «Версия», например `0.7.1a+ab8d181d6611`.

## Правила безопасности

- Расширение **не видит и не хранит** пароли, cookies и коды подтверждения. Входите в Google сами, как обычно.
- Эта сборка **ничего не меняет в Google**. Запись появится в отдельной версии: только с предпросмотром, подтверждением и возможностью вернуть как было.
- Если Google показал капчу, повторный вход или незнакомое окно, расширение останавливается. Пройдите это сами и повторите действие.
- Перед большими изменениями сохраняйте резервную копию: **Менеджер сетей → «Резервная копия»**.

## Нашли ошибку

Пришлите владельцу:
- что нажали;
- что ожидали и что получилось;
- скриншот;
- версию из `chrome://extensions`.
