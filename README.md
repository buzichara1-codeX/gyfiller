# GYfiller (GBP Filler) · расширение Chrome

Панель для сети карточек Google Business Profile. Она читает карточки и список компаний из Google в локальную сеть, позволяет вести единый шаблон и прайс-лист и сверяет карточки перед записью.

**Текущая версия: 0.7.1a.** Это сборка **без записи в Google**: она только читает. Поэтому её можно спокойно пробовать на любом профиле.

## Установка

Ставится один раз, около 5 минут.

1. Установите [GitHub Desktop](https://desktop.github.com/) и войдите в аккаунт, которому открыт доступ к репозиторию.
2. В GitHub Desktop: **File → Clone repository → `buzichara1-codeX/gyfiller`**. Запомните папку, куда он клонировался, например `Документы\GitHub\gyfiller`.
3. Откройте в Chrome `chrome://extensions`.
4. Включите **«Режим разработчика»** (переключатель справа вверху).
5. Нажмите **«Загрузить распакованное расширение»** и выберите папку **`gyfiller\extension`**. Выбирать нужно именно папку `extension`, а не весь репозиторий.
6. Закрепите значок GBP Filler на панели Chrome (значок пазла → булавка).

> Если у вас уже стоит другая копия GBP Filler, сначала выключите её на `chrome://extensions`. Две копии одновременно будут мешать друг другу.

## Обновление

1. GitHub Desktop → **Fetch origin**. Если вышло обновление, нажмите **Pull origin**.
2. `chrome://extensions` → в карточке GBP Filler нажмите **«Обновить»** (круглая стрелка).
3. Откройте заново вкладки Google, с которыми работаете (F5).

Ваши данные (сети, шаблоны, история) хранятся в браузере и при обновлении **не пропадают**, если папка расширения осталась прежней. Не переносите и не переименовывайте папку `extension`: Chrome будет считать её другим расширением, и данные останутся в старом.

Сам Chrome такое расширение не обновит, это происходит только через Chrome Web Store. Пока обновляем вручную: Pull, затем «Обновить».

**Какая версия у меня стоит:** её показывает `chrome://extensions` → GBP Filler → «Версия», например `0.7.1a+ab8d181d6611`.

## Правила безопасности

- Расширение **не видит и не хранит** пароли, cookies и коды подтверждения. Входите в Google сами, как обычно.
- Эта сборка **ничего не меняет в Google**. Запись появится в отдельной версии: только с предпросмотром, подтверждением и возможностью вернуть как было.
- Если Google показал капчу, повторный вход или незнакомое окно, расширение останавливается. Пройдите это сами и повторите действие.
- Перед большими изменениями сохраняйте резервную копию: **Менеджер сетей → «Резервная копия»**.

## Нашли ошибку

Пришлите владельцу:
- что нажали;
- что ожидали и что получилось;
- скриншот;
- версию из `chrome://extensions`.
